# Church Bulletin Publisher

A small WordPress plugin for assembling weekly church bulletins without giving the secretary WordPress or hosting access.

The weekly workflow is deliberately simple:

1. The secretary saves the weekly PDFs into the pre-created Google Drive folder.
2. An administrator chooses that folder, or selects one or more PDFs directly, and enters the bulletin date in WordPress.
3. The plugin builds a private PDF preview from the front cover, weekly pages, inserts, and back cover.
4. The administrator reviews the exact merged PDF.
5. The approved PDF is published and the bulletin list is generated by shortcode.

## Current safety boundary

Version 0.1 is intentionally **test-only**. Its Publish button writes to:

`wp-content/uploads/bulletin-publisher-test/YYYY/MMDDYYbulletin.pdf`

It does not write to the existing `wp-content/bulletins` tree and does not edit the existing bulletin page. Activation creates a draft page named **Bulletin Publisher Test** containing:

`[church_bulletins mode="test"]`

This lets the workflow be exercised on the live WordPress installation without cloning the whole site and without exposing a test page publicly.

## Requirements

- WordPress 6.2 or later
- PHP 7.4 or later

No server PDF program is required. When qpdf or pdfunite is unavailable, the bundled MIT-licensed pdf-lib 1.17.1 library assembles the bulletin in the administrator's browser and uploads only the finished private preview. qpdf or pdfunite is still used automatically when available.

## Install for testing

1. Download the repository as a ZIP.
2. Ensure the ZIP contains the `bulletin-upload-wordpress-plugin` directory as its top level.
3. In WordPress, open **Plugins → Add New Plugin → Upload Plugin**.
4. Upload and activate it.
5. Open **Bulletin Publisher** in the administrator menu.
6. Upload the front and back cover templates.
7. Select a dated weekly folder and create a preview.

Do not publish the draft test page. Logged-in administrators can preview it directly from the plugin screen.

## Verified sample structure

The August 16, 2026 printer PDF contains five letter-size pages:

1. Static front cover
2. Weekly page
3. Weekly page
4. Weekly page
5. Static back cover

Reconstructing it from the supplied front cover, pages 2–4, and supplied back cover produced identical rendered pages. That establishes the initial merge rule:

`front cover + weekly pages + inserts + back cover`

## Shortcode

- Test listing: `[church_bulletins mode="test"]`
- Future live listing: `[church_bulletins]`
- Limit rows: `[church_bulletins limit="20"]`

Live publishing remains disabled in version 0.1 until the test workflow and server environment are verified.
